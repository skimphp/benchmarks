# FrankenPHP Worker Mode Benchmark

Isolated benchmark suite for PHP frameworks running in FrankenPHP worker mode.

## Scope

| Framework     | Mode                        | Port (host) | Service |
|---------------|-----------------------------|-------------|---------|
| Skim          | Native FrankenPHP worker    | 9101        | `skim`    |
| Symfony       | Native FrankenPHP worker    | 9102        | `symfony` |
| Laravel       | Octane + FrankenPHP         | 9103        | `laravel` |
| CodeIgniter 4 | Native FrankenPHP worker    | 9104        | `ci4`     |
| Slim          | Native FrankenPHP worker    | 9105        | `slim`    |
| Leaf          | Native FrankenPHP worker    | 9106        | `leaf`    |
| Flight        | Native FrankenPHP worker    | 9107        | `flight`  |

All images build from the single multi-target `frameworks/Dockerfile` —
the `base` stage (OS deps + PHP extensions + composer) is shared and
cached across targets; each framework stage only runs its composer
install and COPYs its `public/index.php` + `Caddyfile`.

## Endpoints

All frameworks expose two endpoints for parity:
- `GET /` — returns `Hello World`
- `GET /json` — returns `{"time":0.0}`

## Prerequisites

Docker and Docker Compose must be installed.

## Usage

```bash
# Build and start all worker containers
docker compose -f worker_bench/docker-compose.worker.yml up -d --build

# Manual smoke test
curl http://localhost:9101/        # Skim hello
curl http://localhost:9101/json  # Skim json
curl http://localhost:9102/        # Symfony hello
curl http://localhost:9102/json    # Symfony json
curl http://localhost:9103/        # Laravel hello
curl http://localhost:9103/json    # Laravel json
curl http://localhost:9104/        # CI4 hello
curl http://localhost:9104/json    # CI4 json
curl http://localhost:9105/        # Slim hello
curl http://localhost:9106/        # Leaf hello
curl http://localhost:9107/        # Flight hello

# Full benchmark run (hello + json, c=1,10,50,100)
docker compose -f worker_bench/docker-compose.worker.yml run --rm bench

# Quick run (only Skim vs Symfony, c=1,10)
docker compose -f worker_bench/docker-compose.worker.yml run --rm bench \
  php /app/worker_bench/wrk_worker_run.php --variants=skim,symfony --levels=1,10

# Classic (non-worker) FrankenPHP variants — same images, per-request PHP boot.
# Reuses skim_worker_* images, mounts index.classic.php + plain php_server Caddyfile.
docker compose -f worker_bench/docker-compose.classic.yml up -d
# host ports 9201-9207 (9201=skim … 9207=flight)

# Benchmark classic mode (--classic rewrites service names to *-classic)
docker compose -f worker_bench/docker-compose.worker.yml run --rm bench \
  php /app/worker_bench/wrk_worker_run.php --classic

# Traditional nginx + PHP-FPM (no FrankenPHP).
# One shared php-fpm pool behind nginx; fpm_src/ is generated by extracting
# /app from the built skim_worker_* images (see fpm_src note below).
docker compose -f worker_bench/docker-compose.fpm.yml up -d --build
# host ports 9301-9307 (9301=skim … 9307=flight), endpoints / /json /db

# Benchmark FPM mode (targets nginx:9301-9307 on the shared network)
docker compose -f worker_bench/docker-compose.worker.yml run --rm bench \
  php /app/worker_bench/wrk_worker_run.php --fpm

# Stop everything
docker compose -f worker_bench/docker-compose.worker.yml down
docker compose -f worker_bench/docker-compose.classic.yml down
docker compose -f worker_bench/docker-compose.fpm.yml down
```

### fpm_src regeneration

`worker_bench/fpm_src/<fw>/` is a plain copy of each built image's `/app`
(vendor included). After editing files under `frameworks/<fw>/`, resync:

```bash
for fw in skim symfony laravel ci4 slim leaf flight; do
  docker create --name tmp_$fw skim_worker_$fw
  docker cp tmp_$fw:/app/. worker_bench/fpm_src/$fw/
  docker rm tmp_$fw
done
# swap worker entrypoints for classic ones
for fw in skim ci4 slim leaf flight; do
  cp worker_bench/frameworks/$fw/public/index.classic.php worker_bench/fpm_src/$fw/public/index.php
done
# laravel/symfony keep their own public/index.php
rm -f worker_bench/fpm_src/laravel/bootstrap/cache/routes-*.php \
      worker_bench/fpm_src/symfony/var/cache -r
```

`fpm_src/` is gitignored — it is generated material, not source.

## Results

Results are written to `worker_bench/results/<timestamp>/`:
- `hello.json` — Hello World benchmark results per concurrency level
- `json.json` — JSON endpoint benchmark results per concurrency level
- `db.json` — SQL (`SELECT 1` via PDO/pgsql) results per concurrency level
- `meta.json` — run metadata (frameworks, URLs, timestamps)

## Runner flags

- `--variants=skim,symfony` — filter which frameworks to benchmark
- `--levels=1,10,50,100` — concurrency levels to test
- `--threads=N` — number of wrk threads (default: 2)
- `--duration=30s` — wrk duration per test (default: 30s)
- `--classic` — benchmark FrankenPHP classic (non-worker) variants
- `--fpm` — benchmark the nginx + PHP-FPM stack (ports 9301–9307)

## Isolation guarantees

- Compose project name: `skim_worker` (not `skim_framework_self_usage`)
- Docker network: `worker_bench` (not `bench`)
- Host ports: 9101–9107 worker, 9201–9207 classic, 9301–9307 FPM (does not conflict with existing 9001–9009/5434)
- Results directory: `worker_bench/results/` (separate from `benchmarks/results/`)
- Existing suite (`benchmarks/`, root `docker-compose.yml`) is **not modified**
